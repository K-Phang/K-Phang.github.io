    Overview

    This page collects the final source files, design files, fabrication files, and supporting resources for my B1 Propulsion subsystem for Team 201's project, The Duck.

    The purpose of this page is to make the final design files easy to find from one location. The resources below support the schematic, BOM, PCB, power budget, and final report documentation.

    Code Resources

    The final B1 propulsion board did not become a fully standalone working controller because the onboard 3.3 V rail failed and the ESP32 programming-header support was missing. Because of this, the final testing relied on an external ESP32 breadboard/devkit setup where needed.

    The final ESP32 code project ZIP is included below as KPhang_B1_ESP32_Code.zip. This file contains the ESP32 UART and motor-control test code used for the B1 propulsion subsystem.

    Resource File
    ESP32 code project ZIP KPhang_B1_ESP32_Code.zip

    Video Resources

    No final embedded video is currently included on this individual datasheet page. If a final system demonstration video is available, it should be uploaded to YouTube and embedded on this page.

    CAD / Mechanical Resources

    No custom CAD or 3D-printed mechanical part file was required for my individual B1 propulsion PCB documentation. The main deliverables for this subsystem were electrical design files, PCB fabrication files, and board documentation.

    Resource Review

    The most important resources for grading are the schematic PDF, ECAD project ZIP, BOM files, PCB images, and Gerber/JLCPCB fabrication ZIP. These files document the final state of the B1 propulsion hardware and allow the design to be reviewed beyond the rendered website pages.

    The current resource set supports the final report because it includes both human-readable documentation files and source/fabrication files.
